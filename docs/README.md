# aiscan Human Docs

aiscan is a local-first AI input scanner for corporate guideline compliance.

## Start Here

- **使い方ガイド（日本語）**: `docs/human/usage_guide.md`
- English overview: `docs/human/overview.md`
- Japanese (quick): `docs/human/overview_ja_quick.md`
- Japanese (detailed): `docs/human/overview_ja_detailed.md`

## Recommended Reading Order

1. `docs/human/usage_guide.md` for practical how-to (Japanese).
2. `docs/human/overview_ja_quick.md` (or `docs/human/overview.md`) for a 3-minute view.
3. `docs/human/overview_ja_detailed.md` for full design rationale.
4. `policies/scan_rules.yaml` for detection rules and guideline mapping.
5. `docs/ops/ops_checklist.md` for day-to-day checks.

## Sync Policy

- Japanese source of truth: `docs/human/overview_ja_detailed.md`
- `docs/human/overview_ja_quick.md` must be updated in the same change set.
